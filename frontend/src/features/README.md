# Frontend Features

This folder is meant for domain-specific modules.

## Recommended layout

```text
src/features/
├── auth/
│   ├── LoginForm.jsx
│   ├── RegisterForm.jsx
│   └── authApi.js
├── patients/
├── appointments/
├── doctors/
├── billing/
├── prescriptions/
└── dashboard/
```

Use this for feature-level logic and UI that belongs to a business domain.
